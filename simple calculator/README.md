# Calculator in C

A simple menu-driven calculator developed in **C** using the **switch** statement and functions. This project performs basic arithmetic operations while handling common invalid inputs to ensure reliable execution.

## Features

* Menu-driven interface using `switch` statement.
* Uses functions for better code organization.
* Supports arithmetic operations:

  * Addition
  * Subtraction
  * Multiplication
  * Division
  * Modulus
  * (Include any other operations you implemented.)
* Accepts menu choices only between **1 and 7**.
* **Option 7** exits the program.
* Displays an error message for invalid menu choices.
* Prevents division by zero.
* Prevents modulus by zero.
* Simple and easy-to-understand code structure.

## Concepts Used

* C Programming
* Functions
* Switch Statement
* Conditional Statements (`if-else`)
* Loops
* User Input/Output

## How to Run

1. Compile the program using a C compiler.
2. Run the executable.
3. Enter a menu option (1–7).
4. Enter the required numbers.
5. View the result or choose **7** to exit.

## Error Handling

* Invalid menu choices are rejected with an error message.
* Division by zero is not allowed.
* Modulus by zero is not allowed.
