🎯 Number Guessing Game

A simple Number Guessing Game created by Taranveer Singh.

📖 Description

This is a console-based number guessing game where the computer generates a random number and the player tries to guess it.

The program uses the current time as a seed to generate a random number. After each guess, the game tells the player whether their guess is smaller or larger than the correct answer.

The game also keeps track of the number of attempts taken by the player and displays it when the correct number is guessed.

✨ Features
🎲 Generates a random number using time as a seed
🔢 Allows the user to enter guesses
📉 Tells the user when their guess is smaller than the answer
📈 Tells the user when their guess is larger than the answer
🏆 Detects when the correct number is guessed
🔢 Counts and displays the total number of attempts
💻 Simple command-line interface
🎮 How to Play
Start the program.
The computer generates a random number.
Enter your guess.
The program will tell you if your guess is:
Smaller than the answer
Larger than the answer
Correct
Keep guessing until you find the correct number.
Once you guess correctly, the program displays the total number of attempts.
💡 Example
Welcome to the Number Guessing Game!

Enter your guess: 40
Your guess is smaller than the answer.

Enter your guess: 70
Your guess is larger than the answer.

Enter your guess: 55
Congratulations! You guessed the correct number.

Total attempts: 3

⚙️ How It Works

The game uses the current time as a seed for the random number generator. This helps produce a different random number each time the program is run.

The player's guess is then compared with the generated number:

Guess < Answer  →  Guess is smaller
Guess > Answer  →  Guess is larger
Guess = Answer  →  Correct guess


Every time the player makes a guess, the attempt counter increases by 1.
